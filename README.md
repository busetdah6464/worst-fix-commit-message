# Worst Fix Ever: Funniest Commit Message

Entry for [Worst Fix Ever: Funniest Commit Message](https://make.fun/bounty/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722) on make.fun.

One original commit message of at most 100 characters, for the bug fix
that made everything worse. The joke is the specific irony of a repair
that broke more than it mended: the bug that got removed turned out to
be load-bearing, so the build is now held up by hope and a TODO.

`main.py` writes the line to `/output/entry.txt`, deterministically.

Run it with `python3 main.py`; run it twice and the output is byte-identical.
